# LAUNCHLAB FRESHER TRAINING 2ed

This repository contains all the materials related to the basic MOSFET theory, CMOS technology, circuit and layout design, and basic PDK design.

# Linux, Scripting and Programming

[Linux, Scripting and Programming](https://github.com/VLSI-LaunchLab/LFT-linux-scripting-programming) is a mandatory module for all trainees. This module introduces the candidates to Linux OS, linux commands, basic scripting and Python programming. 


# Digital Logic

[Digital Logic](https://github.com/VLSI-LaunchLab/LFT-digital-logic) is the module for all trainees. This modules introduces them to basic digital logic analyis and design. An optional project is included for some trainees who are expected to be in digital domain eg. Design Verification (DV).
