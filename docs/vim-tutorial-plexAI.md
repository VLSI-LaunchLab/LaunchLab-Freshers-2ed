# Suggested `vim` Tutorial 

Here are some excellent Vim tutorials for beginners and intermediate users:

- **Interactive Built-in Tutorial:**
Run `vimtutor` in your terminal. This is Vim’s official, interactive, step-by-step tutorial and is widely recommended as the best starting point for new users. It teaches you practical navigation, editing, and command-line basics directly in Vim itself[^6][^7].
- **Web-Based Written Guides:**
    - [Classic SysAdmin: Vim 101 – A Beginner's Guide to Vim (Linux Foundation)](https://www.linuxfoundation.org/blog/blog/classic-sysadmin-vim-101-a-beginners-guide-to-vim)
A clear, concise introduction to Vim’s modes, navigation, and basic editing, ideal for those new to the editor[^1].
    - [freeCodeCamp Vim Beginner’s Guide](https://www.freecodecamp.org/news/vim-beginners-guide/)
A friendly, step-by-step written tutorial with screenshots, covering the essentials of editing, navigation, and visual mode[^3].
    - [TutorialsPoint Vim Tutorial](https://www.tutorialspoint.com/vim/index.htm)
Covers both beginner and intermediate topics, including navigation, editing, search, and configuration[^4].
- **Video Tutorials:**
    - [Vim Tutorial for Beginners (YouTube, freeCodeCamp)](https://www.youtube.com/watch?v=RZ4p-saaQkc)
A comprehensive, beginner-friendly video guide that walks you through installation, basic commands, and essential workflows[^2].
    - [VIM Essentials Course for Beginners (YouTube, ExamPro)](https://www.youtube.com/watch?v=JYNA9j8SXs4)
Another highly-rated video course focusing on the core Vim skills needed for daily development[^8].
- **In-Depth Learning Resource:**
    - [Learn Vim (the Smart Way) – GitHub Book](https://github.com/iggredible/Learn-Vim)
A free, open-source book that covers Vim fundamentals, advanced topics, customization, and even Vimscript, organized in a progressive manner[^7].

**Recommendation:**
Start with `vimtutor` for hands-on basics, then use the freeCodeCamp or TutorialsPoint guides for reference and deeper understanding. For visual learners, the freeCodeCamp YouTube tutorial is highly recommended. As you grow comfortable, explore the GitHub book for advanced usage and customization.
